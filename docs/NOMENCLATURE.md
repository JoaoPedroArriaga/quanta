# QUANTA MOD - NAMING RULES

> **Document based on QUANTA_MASTERLIST v10.5**
> **Last updated:** 2026-11-16
> **Scope:** Official rules for naming the mod's items, machines, blocks, fluids, and concepts

## 🎯 OVERVIEW

This document defines Quanta Mod's **naming rules**. The goal is to maintain **consistency**, **thematic cohesion**, and **clarity**, avoiding excessive repetition (using "Quantum" for everything) and generic names that could be confused with those in other mods.

**Philosophy:** the player is a **scientist** who discovered Quanta. They name things based on what they **observe** (properties), the **quantum concepts** they know (superposition, entanglement, tunneling), and the mod's **lore** (order, chaos, singularity).

---

## 📦 1. ITEMS (MATERIALS, COMPONENTS, TOOLS)

### 1.1 General rules

1. **"Poetic languages":** items may use names in **Latin, Greek, or other "poetic languages"** (e.g.: *Ferrum*, *Adamas*, *Cuprum*, *Lignum*, *Vitrum*, *Aurum*).
2. **Reference to transformation:** the name should make clear that the item **was something and is now quantum** (e.g.: *Ferrum Conducens* → iron that conducts information; *Adamas Resonans* → diamond that resonates).
3. **Quantum physics concepts:** items may reference quantum concepts (e.g.: *Superposition*, *Entanglement*, *Decoherence*, *Singularity*, *Tunneling*, *Nexus*).
4. **Avoid repetition:** do not use "Quantum" for everything. Vary names with **suffixes** and **concepts**.

### 1.2 Naming patterns

| Item type                | Pattern                            | Example                                 |
| ------------------------ | ---------------------------------- | --------------------------------------- |
| **Infused material**     | [Latin name] + [Observed property] | *Ferrum Conducens*, *Adamas Resonans*   |
| **Component**            | [Base name] + [Type]               | *Ferrum Sheet*, *Cuprum Wire*           |
| **Electronic component** | [Quantum concept] + [Function] | *Quantum Transistor*, *Nexus Capacitor* |
| **Tool**                 | [Thematic name]                    | *Quantum Wrench*, *Resonance Hammer*    |
| **Lore item**            | [Poetic name]                      | *Blank Glyph*, *Quantum Codex*          |

### 1.5 Component names

**Rule:** a component uses the material's **base name** + the component suffix (Sheet, Gear, Wire, Rod, Casing, Frame).

| Material (full name) | Component (short name) | Example                             |
| -------------------- | ---------------------- | ----------------------------------- |
| *Ferrum Conducens*   | *Ferrum*               | *Ferrum Sheet*, *Ferrum Gear*       |
| *Adamas Resonans*    | *Adamas*               | *Adamas Sheet*, *Adamas Gear*       |
| *Cuprum Transmissor* | *Cuprum*               | *Cuprum Wire*, *Cuprum Rod*         |

## 🏭 2. MACHINES

### 2.1 General rules

1. **Machines with "Quanta":** machines that **come into direct contact with Quanta** (infusion, transformation, collapse, etc.) may use **"Quanta"** in their name (e.g.: *Quanta Infuser*, *Quanta Collapser*, *Quanta Densifier*).
2. **Machines without "Quanta":** machines that **do not come into direct contact** with Quanta (processing, generation, etc.) **do not need** a prefix or suffix. They can use **quantum concepts** or the mod's **lore** (e.g.: *Matter Rewriter*, *Void Generator*, *Graviton Stabilizer*, *Superposed Reactor*).
3. **Avoid repetition:** do not use "Quantum" for everything. Vary names with **quantum concepts** (Superposed, Entangled, Singular) or **lore** (Void, Graviton, Matter).

### 2.2 Naming patterns

| Machine type                   | Pattern                | Example                                     |
| ------------------------------ | ---------------------- | ------------------------------------------- |
| **Direct contact with Quanta** | *Quanta* + [Function]  | *Quanta Infuser*, *Quanta Collapser*        |
| **Processing**                 | [Concept] + [Function] | *Matter Rewriter*, *Pattern Encoder*        |
| **Generation**                 | [Concept] + [Function] | *Void Generator*, *Quanta Engine*           |
| **Network**                    | [Concept] + [Function] | *Entangler*, *Tunnel Relay*                 |
| **Multiblock**                 | [Concept] + [Function] | *Graviton Stabilizer*, *Superposed Reactor* |

## 🔌 3. CABLES

### 3.1 General rules

1. **Quanta cables:** the cable that transports **Quanta** may use **"Quanta"** in its name (e.g.: *Quanta Cable*).
2. **Item/fluid/gas cables:** cables that transport **items, fluids, or gases** **do not need** "Quanta" in their names. They can use simple names (e.g.: *Item Cable*, *Pipe*, *Pressurized Pipe*).
3. **Consistency:** the cable has the **same name** across all tiers (the tier changes with the Upgrade Kit, not the name).

### 3.2 Name examples (cables)

| Cable  | Final name         | Rationale         |
| ------ | ------------------ | ----------------- |
| Quanta | *Quanta Cable*     | Transports Quanta |
| Items  | *Item Cable*       | Transports items  |
| Fluids | *Pipe*             | Transports fluids |
| Gases  | *Pressurized Pipe* | Transports gases  |

## 💧 4. FLUIDS AND GASES

### 4.1 General rules

1. **Liquids:** poetic names in Latin/Greek (e.g.: *Liquid Quanta*, *Liquid Chaos*, *Liquid Order*).
2. **Gases:** names derived from the liquids (e.g.: *Quanta Gas*, *Chaos Gas*, *Order Gas*).
3. **Avoid repetition:** consistently use **"Liquid"** for liquids and **"Gas"** for gases.

### 4.2 Name examples (fluids)

| Fluid       | Final name           |

| Base        | *Liquid Quanta*      |

| Order       | *Liquid Order*       |
