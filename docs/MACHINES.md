# QUANTA MOD - QUANTA MACHINES (OVERVIEW)

> **Document based on QUANTA_MASTERLIST v10.6**
> **Last updated:** 2026-11-16
> **Scope:** Overview of all Quanta machines by Tier

## 🎯 OVERVIEW

Quanta machines are divided into **4 Tiers** (Decoherent, Entangled, Superposed, Singular) + **multi-tier** (work at any Tier).

**Philosophy:** each Tier adds **new machines** and **upgrades** for existing ones. The names balance the **scientific** and the **poetic**.

**Note:** all machines start at **Tier 1 (Decoherent)** and can be upgraded with an **Upgrade Kit**.

## 🔗 INTEGRATION

- **Tier 1:** introduces Q, Pulvis Nexus, Ferrum Conducens.
- **Tier 2:** introduces liquids/gases, Essences, Aeternum, Quanta Purifier.
- **Tier 3:** introduces auto-crafting, duplication, massive generation, Quanta Weaver.
- **Tier 4:** introduces Singularity, implants, endgame.
