# QUANTA MOD - ARMORS

> **Document based on QUANTA_MASTERLIST v10.6**
> **Last updated:** 2026-11-16
> **Scope:** Armor and armor components in Quanta Mod

## 🎯 OVERVIEW

Quanta Mod has **modular armor** (like its tools):

- **4 pieces:** Helmet, Chestplate, Leggings, Boots.
- **Components:** Armor Plate, Armor Core, Armor Trim.
- **Tiers:** Decoherent, Entangled, Superposed, Singular.

**Philosophy:** each armor piece is assembled from **components** (Plate + Core + Trim). The tier determines its stats (protection, durability, modules).

## ⚠️ 6. BALANCE NOTES

- **Armor:** each piece uses **Plate + Core + Trim**.
- **Tiers:** each tier has more module slots and greater Q capacity.
- **Modules:** improve the armor (mining, combat, utility, defense).
- **Tier 4 (Singular):** the most powerful armor (12 module slots, 75,000 Q).
