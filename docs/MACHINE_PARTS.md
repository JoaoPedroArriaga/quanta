# QUANTA MOD - MACHINE PARTS

> **Document based on QUANTA_MASTERLIST v10.6**
> **Last updated:** 2026-11-16
> **Scope:** Thematic components (parts) used to craft machines

## 🎯 OVERVIEW

**Machine Parts** are **thematic components** used to craft machines. Unlike **Cores** (which are functional), Parts are **structural** — they give machines their "shape" and "personality".

**Philosophy:** each machine has a **unique part** that defines it. The Crusher has a "Crusher Head," the Mixer has a "Whisker" (impeller), the Furnace has a "Heat Chamber," etc.

**Note:** complete machine recipes (Part + Core + Casing + Frame) are in the `RECIPES_TIER*` documents. This document defines **Parts only** (structural).

**Important:** **Tier 0** Parts use **vanilla items only** (no Quanta items). **Tier 1+** Parts use **Quanta items** (Ferrum, Adamas, etc.).

## ⚠️ 7. BALANCING NOTES

- **Tier 0:** Parts use **vanilla items** (Iron, Copper, Blaze Powder, Magma Cream, Iron Chain, Piston).
- **Tier 1+:** Parts use **Quanta items** (Ferrum, Adamas, Aeternum, Superpositum, Singular).
- **Machine Parts** are **structural** (not functional).
- **Cores** are **functional** (processing, energy, fluid, control).
- **Each machine** has **1 Part** + **1 Core** + **Casing** + **Frame**.
